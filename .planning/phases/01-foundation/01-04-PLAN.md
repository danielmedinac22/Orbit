**Step 1 — Collect workspace data:**
Read these files to gather counts and state:

Notes:
- Count `.md` files in `.orbit/notes/` (total)
- Count notes from this week (filename starts with current YYYY-Wxx or date >= Monday of this week)

Themes:
- Count directories in `.orbit/themes/` excluding `_suggested/` (active themes)
- Count directories in `.orbit/themes/_suggested/` (suggested themes)
- For each active theme, get its directory name and read `action-items.md` to count pending items

Action Items:
- Read `.orbit/action-items/pending.md` and count rows in the table where status is "pending"
- Count overdue items: rows where due date exists and is before today and status is "pending"

Decisions:
- Count rows in `.orbit/decisions/log.md` table (total decisions logged)
- Count rows where status is "conflicting" or "stalled" (if any)

Artifacts:
- Count `.md` files in `.orbit/artifacts/` plus `.md` files in `.orbit/themes/*/artifacts/` directories

Last brief:
- Find the most recent file in `.orbit/briefs/` (sort by filename — dates are prefixed)

**Step 2 — Display spatial output:**

- Notes → Signals
- Themes → Constellations

─────────────────
